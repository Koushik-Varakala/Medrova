## 🚀 What is Medrova?

**Medrova** is a healthcare staffing marketplace designed to make healthcare recruitment **faster, safer, and more transparent**.

The platform connects:

- 👨‍⚕️ Doctors
- 👩‍⚕️ Nurses
- 🧑‍🔬 Technicians
- 🏥 Clinics
- 🏨 Healthcare facilities

through a structured digital staffing workflow supporting both **short-term locum staffing** and **permanent healthcare recruitment**.

> **Healthcare Staffing, Finally Done Right.**

Medrova is initially launching in **Hyderabad, Telangana, India**, with a long-term vision of building trusted staffing infrastructure for healthcare organizations across India.

---

## 🎯 The Problem

Healthcare staffing continues to face several operational challenges:

| Challenge | Traditional Process | Medrova |
|---|---|---|
| 🔐 Credential Trust | Difficult to verify | Manual credential verification |
| ⚡ Staffing Speed | Slow & fragmented | Centralized digital workflow |
| 💰 Payment Security | Uncertain payment timelines | Direct professional payments |
| 🔎 Talent Discovery | Informal networks | Verified professional marketplace |
| 📋 Recruitment | Multiple disconnected channels | Locum + permanent hiring |
| 📍 Opportunity Discovery | Limited visibility | Location & specialty-based discovery |

Medrova is built to solve these problems through a **trust-first healthcare staffing ecosystem**.

# 💳 Medrova Credits

Medrova uses a prepaid credit model for clinic-side locum confirmations.

### Current model

```text
Register Clinic
      ↓
Purchase Medrova Credits
      ↓
Find Verified Professional
      ↓
Confirm Professional
      ↓
1 Credit Used
      ↓
Professional Contact Details Unlocked
```

Current pricing starts from:

### **₹750 per locum confirmation**

The model provides clinics with a predictable platform fee while allowing professionals to retain their quoted earnings.

### Pricing principles

- No clinic subscription
- No hidden fees
- No commission from professional earnings
- Free permanent job posting

---

# 💰 Direct Professional Payments

Medrova's current model is designed so healthcare professionals receive **100% of their quoted pay directly from the clinic**.

Supported payment methods include:

- UPI
- Cash

The platform currently promotes a **24-hour payout commitment** for completed shifts.

# 💻 Getting Started

## Prerequisites

Make sure you have:

- Node.js
- npm
- Git
- A Supabase project

---

## 1. Clone the Repository

```bash
git clone https://github.com/Koushik-Varakala/Medrova.git
cd Medrova
```

---

## 2. Install Dependencies

```bash
npm install
```

---

## 3. Configure Environment Variables

Create:

```text
.env.local
```

Example:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Additional environment variables may be required depending on the enabled services, including:

- Server-side Supabase operations
- Payment providers
- External APIs
- Storage
- Application services

> ⚠️ **Never commit `.env.local` or private credentials to GitHub.**

---

## 4. Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
